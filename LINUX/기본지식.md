- Windows의 경우엔 확장자가 파일종류를 판단하지만 리눅스는 별 의미 없다. 실행/텍스트 파일이던 보통 확장명은 없고 있어도 파일의 종류의 절대적 의미가 아니다. file명령어를 사용해서 파일의 종류를 판단한다.

    - Port , 정보를 주고받기 위한 약속된 입출 구역, 약속되어있기 때문에 ip뒤에 쓸 필요가 없다
        - 웹 브라우저의 port는 80 번으로 약속되어 있다
        - ssh 서버를 설치하면 ssh는 22번 포트로 약속 되어있다
            - linux 에서 확인 해보자
            ```
            (sudo) nano /etc/ssh/ssh_config~ 
            page down 해보면 port 22라는 것이 보인다
            ```

    - port forwarding , ip를 할당받은 private ip가 정보를 돌려준다
        - private ip(Guest)에 접근하려면 public ip(Host)에서 private의 ip를 설정해야한다
        - 여기서 public ip는 port 번호를 임의로 지정해서 public ip:privateIp의포트번호 로 외부 사용자가 접속하면 private ip로 접근하게 된다
        - 웹 서버로 접근하게 되면 자동으로 80으로 가고 ssh면 자동으로 22번으로 들어가게 되는 구조이다.
